How ClaudeSwitcher works

Each instance launches the real Claude Desktop app with its own isolated profile under %APPDATA%\Claude-…, so different accounts stay logged in and run side by side.

First-time login for a new account (quiet-login): because a running Claude re-claims the claude:// sign-in link, ClaudeSwitcher briefly closes every Claude window, temporarily makes the new instance the default profile, and lets you sign in there. The callback lands in the right place, then ClaudeSwitcher swaps everything back and reopens your windows. You only do this once per account; after that the instance runs concurrently with the rest and never needs it again.

Cowork note: the Cowork VM can only run in one account at a time (a Windows limitation); chat and Claude Code work in every instance.

First-time login

  1. ClaudeSwitcher closes all Claude windows and opens only this instance (signed out).
  2. Sign in there with this instance's account.
  3. Come back and click Done — I'm signed in.
  4. ClaudeSwitcher reopens your main Claude next to it.
